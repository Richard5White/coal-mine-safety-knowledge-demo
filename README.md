# 煤矿安全风险知识图谱系统原型

这是“煤矿安全风险知识图谱智能构建与时序演化推理”项目的系统原型。系统整理官方公开法规与事故案例索引，并使用预置场景数据展示知识查询、风险关系追溯、时序演化、知识图谱构建和大模型协同推理流程。

> 重要说明：法规名称、文号、事故伤亡与原因摘要来自界面所列官方公开来源；设备台账、监测序列、抽取规模、质量分数和推理结果为演示数据，不可用于实际煤矿安全决策。

## 运行要求

- Windows 10 或 Windows 11
- Python 3.9 或更高版本
- Chrome、Edge 或其他现代浏览器
- 不需要安装数据库、Node.js 或任何 Python 第三方包

## Windows 一键运行

1. 双击 `run.bat`。
2. 浏览器会打开 `http://127.0.0.1:8000`。
3. 如果浏览器打开较快，页面暂时无法访问，等待两秒后刷新即可。
4. 演示结束后，关闭命令行窗口，或在命令行中按 `Ctrl+C`。

## 命令行运行

在本目录打开 PowerShell：

```powershell
py -3 server.py
```

如果系统没有 `py` 命令：

```powershell
python server.py
```

然后访问：

```text
http://127.0.0.1:8000
```

## 1—2 分钟快速演示

1. 建议将浏览器设为全屏（`F11`），分辨率使用 1920×1080 或更高。
2. 启动 Windows 录屏、OBS 或其他录屏软件。
3. 点击页面上方的“快速演示”。
4. 页面内光标会依次完成主模块切换，并打开、操作和关闭各页的内嵌专题工作台。
5. 实测全流程约 106 秒，结束时停留在“测试验证”界面。
6. 需要中途停止时按 `Esc`；也可以按 `Alt+D` 快速启动。

自动顺序依次覆盖：项目必要性、瓦斯风险研判、证据补查、时序演化、知识子图、八阶段图谱构建、GraphRAG 协同调试、知识质量处置和离线评测复现。

每个大页面都提供一个“打开……台”按钮。子界面包含 3 个专题视图，可继续点击关系节点、检查项、证据卡和执行按钮。

## 顶部业务模块

- **风险研判**：输入安全问题，查看风险关系、时序演化、依据与处置建议。
- **知识图谱**：浏览煤矿安全知识全景，点击实体节点查看属性、关系和知识来源。
- **图谱构建**：查看14份官方资料索引、八阶段构建流水线、领域本体、关系类型、三元组溯源和大模型融合机制。
- **模型协同**：演示问题理解、GraphRAG检索增强、规则校验、证据约束生成与专家回写。
- **测试验证**：查看样本切分、方法对比、六项指标和固定样本离线复现。
- **数据治理**：查看多源数据接入、知识构建流水线、质量指标和待复核冲突。

七个模块可以通过页面顶部导航直接切换，不会重新加载页面。

## 文件结构

```text
coal_mine_demo/
├─ server.py              Python 本地服务器和系统 API
├─ run.bat                Windows 一键启动脚本
├─ index.html             页面结构
├─ styles.css             视觉样式
├─ app.js                 交互、图谱和视图控制
└─ data/
   ├─ scenarios.json      预置问题、答案、图谱与时序数据
   └─ knowledge-base.json 官方公开资料索引、本体、关系与构建流程演示数据
```

## 修改演示内容

主要内容位于 `data/scenarios.json`。可以修改：

- `question`：预设问题
- `summary`：风险结论
- `riskChain`：风险链
- `graph.nodes` 和 `graph.edges`：图谱节点与关系
- `timeline`：时序演化事件
- `evidence`：规程、设备和监测依据
- `recommendations`：辅助处置建议

修改并保存后刷新浏览器即可，不需要重启 Python 服务。
