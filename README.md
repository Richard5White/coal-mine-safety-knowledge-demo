# 煤矿安全风险知识图谱系统原型

这是“煤矿安全风险知识图谱智能构建与时序演化推理”项目的系统原型。系统使用预置样例数据，展示知识查询、风险关系追溯、时序演化和新工作面冷启动推理流程。

> 重要说明：界面中的数据、条款编号、风险分数和推理结果均为演示样例，不可用于实际煤矿安全决策。

## 运行要求

- Windows 10 或 Windows 11
- Python 3.9 或更高版本
- Chrome、Edge 或其他现代浏览器
- 不需要安装数据库、Node.js 或任何 Python 第三方包

## Windows 一键运行

1. 双击 `run.bat`。
2. 浏览器会打开 `http://127.0.0.1:8000`。
3. 如果浏览器打开较快，页面暂时无法访问，等待两秒后刷新即可。
4. 演示结束后，关闭命令行窗口，或在命令行中按 `Ctrl+C`。

## 命令行运行

在本目录打开 PowerShell：

```powershell
py -3 server.py
```

如果系统没有 `py` 命令：

```powershell
python server.py
```

然后访问：

```text
http://127.0.0.1:8000
```

## 三分钟讲解操作顺序

界面本身不显示倒计时或演示控制。讲解人员按照下列自然操作完成介绍：

| 时间 | 演示内容 | 建议讲解重点 |
|---|---|---|
| 0:00–0:25 | 场景介绍 | 指出当前问题和系统汇聚的知识范围 |
| 0:25–1:00 | 点击“开始智能研判” | 融合规程、设备状态和监测事件 |
| 1:00–1:40 | 讲解关系图谱 | 通风机异常如何传导至瓦斯积聚 |
| 1:40–2:10 | 讲解右侧依据 | 每个结论都可回到规程、设备和监测来源 |
| 2:10–2:35 | 点击“时序演化” | 展示事件顺序和候选后继风险 |
| 2:35–3:00 | 点击第二个常用问题 | 新工作面参考同类风险模式，结果仍需专家复核 |

这一顺序可以自然覆盖约三分钟，不会在业务界面中出现任何演示提示。

## 顶部业务模块

- **风险研判**：输入安全问题，查看风险关系、时序演化、依据与处置建议。
- **知识图谱**：浏览煤矿安全知识全景，点击实体节点查看属性、关系和知识来源。
- **数据治理**：查看多源数据接入、知识构建流水线、质量指标和待复核冲突。

三个模块可以通过页面顶部导航直接切换，不会重新加载页面。

## 文件结构

```text
coal_mine_demo/
├─ server.py              Python 本地服务器和系统 API
├─ run.bat                Windows 一键启动脚本
├─ index.html             页面结构
├─ styles.css             视觉样式
├─ app.js                 交互、图谱和视图控制
└─ data/
   └─ scenarios.json      预置问题、答案、图谱与时序数据
```

## 修改演示内容

主要内容位于 `data/scenarios.json`。可以修改：

- `question`：预设问题
- `summary`：风险结论
- `riskChain`：风险链
- `graph.nodes` 和 `graph.edges`：图谱节点与关系
- `timeline`：时序演化事件
- `evidence`：规程、设备和监测依据
- `recommendations`：辅助处置建议

修改并保存后刷新浏览器即可，不需要重启 Python 服务。
